# Cattle Sprayer Mesh (Home Assistant)

Public HACS package: https://github.com/Bluey78532/cattle-sprayer-mesh-ha

This folder in the product repo is the development copy. Push updates to the public repo for farmers/HACS.

Connects Home Assistant to a house MeshCore gateway over **Wi‑Fi (TCP 5000)**, **USB**, or **BLE**, applies the SoftAP pairing card, and creates sprayer devices from `CS …` channel messages.
